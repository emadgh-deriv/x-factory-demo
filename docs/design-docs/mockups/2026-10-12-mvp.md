# MVP: headline list → article

Date: 2026-10-12 · Status: Built · Mockup: [2026-10-12-mvp.html](2026-10-12-mvp.html)
Data: Guardian Open Platform Content API (unversioned REST), checked live 2026-10-12.
Profile: [PROFILE.md](PROFILE.md) · Scope: [mvp.md](../../mvp.md)

## Intent
The user opens Sport-Radar and sees the newest Guardian sport stories as a list of cards
(image, headline, trail text, byline, time). They tap one and read the full article in-app,
with a link out to The Guardian. Back returns them to the same spot in the list, and "Load
more" brings in the next 20.

## Data reality
| Reference (idea / mvp.md) has | Data has | Mockup does |
|---|---|---|
| List of sport news | `/search?section=sport&order-by=newest`, ~199k results, 20 per page | List of cards, 20 per page |
| Thumbnail per item | `fields.thumbnail` (500 px wide JPG). Present on all 8 sampled; not guaranteed | 16:10 image; placeholder with sport icon if missing |
| Short summary | `fields.trailText`, **contains HTML** (`<strong>`, links) | Strip tags to plain text, clamp 2 lines (3 on desktop) |
| Author | `fields.byline`, sometimes missing or "Guardian sport" | Show if present, else hide the line's byline part |
| Time | `webPublicationDate` ISO UTC | Relative time ("3 h ago") under 24 h, else "11 Oct" |
| Live coverage (not in idea) | `type: "liveblog"` (2 of 8 sampled) | "Live" badge on card. Article body of a live blog is long; rendered the same (see Q2) |
| Article detail | `/{id}?show-fields=headline,standfirst,byline,main,body` | Headline, standfirst, byline, date, main image, body |
| Main image + caption | `fields.main`: `<figure>` HTML with `<img>` + `<figcaption>` | Render sanitised figure; caption below |
| Full text | `fields.body`, HTML ~34 KB, may embed tweets/iframes | Sanitise: keep text, links, images, lists, quotes, headings; drop scripts/iframes/embeds |
| Link out | `webUrl` | "Read on The Guardian" outlined button + top-bar icon |
| Unknown article | API returns 404 | Not-found screen |

Endpoints (both via Next.js server, `api-key` header):
- List: `GET /search?section=sport&order-by=newest&page-size=20&page={n}&show-fields=thumbnail,trailText,byline`
  → `response.results[]`, `response.currentPage`, `response.pages`.
- Article: `GET /{id}?show-fields=headline,standfirst,byline,main,body` → `response.content`.

Fields left out: `sectionName`/`pillarName` (always "Sport"), `webTitle` on article (use
`fields.headline`, fall back to `webTitle`), tags, `wordcount` (not needed for MVP).

Derived values:
- Relative time: `< 1 min` "Just now"; `< 60 min` "{m} min ago"; `< 24 h` "{h} h ago"; else
  "d MMM" (add year if not current year). Hover/`title` shows full local date-time.
- Live badge: `type === "liveblog"`.
- Trail text: HTML stripped, entities decoded.
- Article route: `/article/{id}` with `id` kept as-is (contains slashes; catch-all route).
- "Load more" hidden when `currentPage >= pages`. Dedupe by `id` when appending.

### 2 · Article
```
┌──────────────────────────────────────────────┐
│ ← (9)  Sport-Radar                    ↗ (10) │
├──────────────────────────────────────────────┤
│   [Live]                                     │
│   Headline, display/headline-large (11)      │
│   Standfirst, body-large, variant (12)       │
│   Dave Schilling · Mon 12 Oct 2026, 08:00(13)│
│   ┌──────────────────────────────────────┐   │
│   │          main image 16:9 (14)        │   │
│   └──────────────────────────────────────┘   │
│   caption, body-small                        │
│   Body paragraphs, body-large (15)           │
│   …                                          │
│   [ ↗ Read on The Guardian ] (16)            │
└──────────────────────────────────────────────┘
```
| # | Element | Behaviour |
|---|---|---|
| 9 | Back | Icon button `arrow_back`. Browser back if history exists, else `/`. |
| 10 | Open original | Icon button `open_in_new`, opens `webUrl` in new tab. Tooltip "Read on The Guardian". |
| 11 | Headline | `fields.headline`. headline-large desktop, headline-medium mobile. Live badge above when liveblog. |
| 12 | Standfirst | `fields.standfirst`, sanitised HTML, body-large, on-surface-variant. Hidden if missing. |
| 13 | Byline + date | label-large; full local date "Mon 12 Oct 2026, 08:00". |
| 14 | Main image | From `fields.main` figure; 12 px radius, 16:9 cover, caption below in body-small. Hidden if missing or not an image (e.g. video embed). |
| 15 | Body | Sanitised `fields.body`, body-large, line-height 1.6, max 720 px. Links open in new tab. Inline images full width with captions. |
| 16 | Read on The Guardian | Outlined button with `open_in_new`, at end of article. |

Landscape: content column 720 px centred, the top bar stays 64 px; everything else scrolls.

### 3 · List loading
6 skeleton cards (same sizes as #3) with a shimmer; top bar and heading render immediately.
### 4 · Article loading
Top bar with back; skeletons for headline (2 lines), standfirst, meta, image 16:9, 5 body lines.
### 5 · List error / rate-limited
Centered: `cloud_off` icon, "Can't load sport news", supporting text ("The Guardian didn't
respond. Check your connection and try again." / for 429: "Too many requests right now. Try
again in a minute."), filled button "Retry". Same pattern for an article that fails with 5xx.
### 6 · List empty
`newspaper` icon, "No sport news right now", "Check back later.", tonal button "Refresh".
### 7 · Article not found
`search_off` icon, "Article not found", "It may have been moved or removed.", filled button
"Back to latest sport".

## States
| State | Behaviour |
|---|---|
| Loading | Screens 3 and 4. Skeletons keep final sizes, so no layout jump. |
| Empty | Screen 6 (`results` empty). |
| Filtered-to-empty | Not applicable (no search/filter in MVP; search is backlog #1). |
| Error / service down | Screen 5 for list, same pattern in article. 429 has its own copy. Load-more failures are inline and keep loaded cards. |
| Slow network | Skeletons until data; images fade in over a fixed-size placeholder. |
| Not found | Screen 7 for API 404. |
| Not applicable | Sign-in, settings, themes switch (backlog). |

The article page and list are independent server routes: an article failure never breaks the
list, and the list stays cached for 60 s (articles 10 min) so a brief outage still serves.

## Decisions (approved 2026-10-12, proposals accepted)
1. `@material/web` components + custom MD3-token cards and top app bar.
2. Live blogs render in-app like articles, with the Live badge.
3. "Load more" button, not infinite scroll.
4. Trail text hidden in mobile landscape.
